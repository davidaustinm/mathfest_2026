    Section 4 Linear independence

    A version of this activity appears in Understanding Linear Algebra by David Austin.
    🔗

    Objectives

    • Strengthen the connection between questions about linear combinations and questions about the consistency of linear systems.
      🔗
      🔗
    • Develop a geometric condition that explains when the span of a set of vectors is the same as the span of a proper subsect of those vectors.
      🔗
      🔗
    • Determine how the reduced row echelon form of a matrix explains when the span of the columns is the same as the span of a proper subset of those columns.
      🔗
      🔗
    🔗

    Subsection 4.1 Some background

    At this point of the course, students have encountered linear combinations of vectors and the concept of the span of a set of vectors. As a reminder, an example of a linear combination of vectors \(\vvec\) and \(\wvec\) is
    \begin{equation*} 2\vvec - 3\wvec\text{.} \end{equation*}
    Asking whether a given vector is a linear combination of a set of vectors is the same as asking about the consistency of an associated linear system.
    🔗
    Also, the span of a set of vectors is the set of all linear combinations that can be formed from the vectors.
    🔗
    The next activity provides a “Sage cell” as a way for students to explore. For thos unfamiliar with Sage, some background is provided below.
    🔗

    Sage background.
    Given vectors \(\vvec=\twovec23\) and \(\wvec=\twovec{-3}4\text{,}\) we can ask whether \(\twovec{13}{-6}\) is a linear combination of these vectors by constructing the augmented matrix and finding its reduced row echelon form, such as
    \begin{equation*} \left[\begin{array}{cc|c} 2 \amp -3 \amp 13 \\ 3 \amp 4 \amp -6 \\ \end{array}\right] \sim \left[\begin{array}{cc|c} 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp -3 \\ \end{array}\right]\text{,} \end{equation*}
    which tells us that
    \begin{equation*} \twovec{13}{-6} =2\vvec - 3\wvec\text{.} \end{equation*}

    Worksheet 4.2 Introduction to linear independence
    

    Activity 4.1.

    We will begin by exploring the span of two sets of vectors using the following Sage cell.
    🔗

    (a)

    Consider the set of vectors
    \begin{equation*} \vvec_1=\threevec0{-1}2,~~~~ \vvec_2=\threevec31{-1},~~~~ \vvec_3=\threevec201\text{.} \end{equation*}
    Is it possible to write the vector \(\threevec310\) as a linear combination of these vectors? If so, how can it be written as a linear combination?
    🔗
    How about the vector \(\threevec311\text{?}\)
    🔗
    🔗

    (b)

    Express these results by writing a sentence or two using the concept of span.
    🔗
    🔗

    (c)

    Find the reduced row echelon form of the matrix \(A\) whose columns are \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\text{:}\)
    \begin{equation*} A = \begin{bmatrix}\vvec_1 \amp \vvec_2 \amp \vvec_3 \end{bmatrix}\text{.} \end{equation*}
    What does this tell us about the span of the set of these vectors; in particular, is every vector in \(\real^3\) in the span of this set of vectors?
    🔗
    🔗

    (d)

    We now consider the set of vectors
    \begin{equation*} \wvec_1=\threevec0{-1}2,~~~~ \wvec_2=\threevec31{-1},~~~~ \wvec_3=\threevec301\text{.} \end{equation*}
    Is it possible to write the vector \(\threevec310\) as a linear combination of these vectors? If so, how can it be written as a linear combination?
    🔗
    How about the vector \(\threevec311\text{?}\)
    🔗
    🔗

    (e)

    Find the reduced row echelon form of the matrix \(B\) whose columns are \(\wvec_1\text{,}\) \(\wvec_2\text{,}\) and \(\wvec_3\text{:}\)
    \begin{equation*} B = \begin{bmatrix}\vvec_1 \amp \vvec_2 \amp \vvec_3 \end{bmatrix}\text{.} \end{equation*}
    What does this tell us about the span of the set of these vectors; in particular, is every vector in \(\real^3\) in the span of this set of vectors?
    🔗
    🔗

    (f)

    We have now considered two sets of three vectors in \(\real^3\text{.}\) In one case, the span is \(\real^3\) and in the other case, it is not. We would like to understand the difference in these two examples.
    🔗
    Are you able to write \(\vvec_3\) as a linear combination of \(\vvec_1\) and \(\vvec_2\text{.}\) How does the reduced row echelon form of \(A\) help us answer this question?
    🔗
    Are you able to write \(\wvec_3\) as a linear combination of \(\wvec_1\) and \(\wvec_2\text{.}\) How does the reduced row echelon form of \(B\) help us answer this question?
    🔗
    🔗

    (g)

    Explain why a linear combination of the vectors \(\wvec_1\text{,}\) \(\wvec_2\text{,}\) and \(\wvec_3\) can be rewritten as a linear combination of \(\wvec_1\) and \(\wvec_2\) alone.
    🔗
    🔗

    (h)

    Explain why
    \begin{equation*} \laspan{\wvec_1,\wvec_2,\wvec_3} = \laspan{\wvec_1,\wvec_2}\text{.} \end{equation*}
